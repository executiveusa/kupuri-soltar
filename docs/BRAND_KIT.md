## Logo Mark

A double-loop knot (interlocked teardrops / lemniscate) above the wordmark.

```
  ∞ ∞
 SOLTAR
```

**Rules:**
- Always render as a single-color mark
- Minimum clear space: half the logo height on all sides
- Never distort, rotate, or add effects
- Two approved versions: dark (cream on dark) and light (ink on parchment)

## Typography

### Primary: Cormorant Garamond (Google Fonts)
- **Display headings**: Cormorant Garamond 300–400, generous line height
- **Body serif**: Cormorant Garamond 300 italic for quotes and poetry
- **Language use**: ES, EN, JA all use Cormorant; Japanese falls back to Hiragino Mincho

### Secondary: Inter (Google Fonts)
- **UI labels, captions, small print**: Inter 300–400
- **Tracking**: `tracking-wide` for nav, `tracking-[0.25em]` for uppercase labels

### Scale
| Role | Size | Weight | Style |
|---|---|---|---|
| Display | 3.5rem | 300 | Normal |
| Display SM | 2.5rem | 400 | Normal |
| Body serif | 1.125–1.25rem | 300 | Italic for quotes |
| UI label | 0.75rem | 400 | Uppercase, wide tracking |
| Pillar line | 0.75rem | 400 | Wide tracking |

## Button System

### Pill Button (App)
- Shape: fully rounded (border-radius: 9999px)
- Background: `rgba(237,229,216,0.14)` + `backdrop-filter: blur(12px)`
- Border: `1px solid rgba(237,229,216,0.35)`
- Text: cream, Cormorant Garamond, 1.125rem, tracking 0.04em
- Hover: background opacity → 0.24, border opacity → 0.55

### Ghost (App)
- No background
- Text: cream-dim, italic serif
- Hover: underline

## Photography Direction

**On-brand:**
- Women of multiple races, calm seated posture
- Natural textures: linen, cotton, tatami, paper, wood
- Candlelight as warm accent light source
- Cherry blossom as soft atmospheric detail (not costume)
- Mountain mist backgrounds — painterly, ukiyo-e influenced
- Hands holding objects gently (folded cloth, a book, a candle)

**Never:**
- Harsh studio lighting
- Exaggerated emotion or "empowerment poses"
- Products displayed like advertising
- Japanese symbols used as decoration only

## Brand Voice

**Do:** Speak gently. Short sentences. Invite, don't command. Pause-worthy.
**Don't:** Urgency. Scarcity. Hype. Productivity language. Influencer tone.
