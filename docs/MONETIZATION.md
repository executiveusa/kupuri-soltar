# Monetization — SOLTAR

## Free Core (Always Free)

These features are permanently free. No paywall, no forced signup.

- Five-step release path (Ropa → Libros → Papeles → Komono → Recuerdos)
- Local reflection journal (device-only, no sync required)
- Bitácora essays
- Reading Cartas de Soltar (anonymous letters)
- Printable checklists
- Multilingual guidance (Spanish, English, Japanese)

## Optional Paid (Later)

These are future offerings — not built yet. They are added only after the free core is stable.

| Offering | Type | Notes |
|---|---|---|
| Guided journey packs | Content | Deep-dive themed journeys |
| Printed journals | Physical | Premium mail-order journals |
| Facilitator kits | B2B | For therapists, organizers, coaches |
| Encrypted private sync | Feature | Optional cross-device sync with E2E encryption |
| Donations | Support | Voluntary contribution, no pressure |
| Sponsorships | Partnership | Values-aligned only, clearly labeled |
| White-label Soltar deployments | B2B | Custom deployments for organizations |

## Forbidden Revenue Models

These will never be used:

- Ads of any kind
- Selling or sharing user data
- Manipulative subscription flows (dark patterns, auto-renew traps)
- Paywalling vulnerable moments (mid-session, mid-reflection)
- Urgency discounts ("Only 3 hours left!")
- Engagement maximization features
- Social comparison leaderboards

## Build Order

1. Free core works completely — **now**
2. Encrypted sync — **when user base justifies it**
3. Printed journals — **after at least 100 completions**
4. Everything else — **community-driven, not growth-driven**
